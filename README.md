# Café SofIA — Prototipo

Prototipo navegable de Café SofIA (kiosco de campus ADEN Costa Rica), generado a partir del prompt de la Clase 5.

## Cómo correrlo

1. Instalar dependencias:
   npm install

2. Levantar el servidor de desarrollo:
   npm run dev

3. Abrir la URL que muestra la terminal (normalmente http://localhost:5173)
